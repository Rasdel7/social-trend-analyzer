# Social Media Trend Analyzer 📱

Analyzes trending topics, hashtags, sentiment
and engagement patterns across 6 platforms.

## Live Demo
[Click here](https://social-trend-analyzer-4qulzfdaed9cwz8rdvk2ym.streamlit.app)

## Features
- Top trending hashtags visualization
- Sentiment analysis by topic and platform
- Engagement analytics (likes, retweets, replies)
- Best time to post analysis
- Hourly activity with dual-axis chart
- Word cloud generation
- Platform comparison

## Topics Covered
Cricket, Technology, Bollywood, Politics,
Finance, Education, Environment, Health

## Tools Used
- Python, Streamlit, Plotly, VADER, WordCloud

## How to Run Locally
pip install streamlit pandas numpy plotly vaderSentiment wordcloud matplotlib
streamlit run app.py
